# T4 - Chatbot para MPStudio

## 1. Objetivo del chatbot

### ¿Para qué sirve dentro de la landing?
El chatbot de MPStudio es un asistente virtual integrado en la landing page que guía al visitante a través de un árbol de conversación interactivo. Su función es responder preguntas frecuentes de forma automática y dirigir al cliente potencial hacia una consulta por WhatsApp o el formulario de contacto.

### ¿Qué problema resuelve?
Resuelve la barrera de contacto inicial — muchos visitantes tienen dudas sobre precios, tiempos y servicios pero no se animan a escribir directamente. El chatbot les da respuestas inmediatas de forma amigable y los lleva naturalmente hacia la conversión.

## 3. Implementación técnica

### Interfaz
- Botón flotante fijo en la esquina inferior derecha
- Ventana emergente (modal) con animación de entrada
- Header con avatar, nombre y estado en línea

### Estructura
- Input de texto con detección de Enter
- Área de conversación con historial scrolleable
- Indicador de escritura animado (tres puntitos)

### Lógica de respuestas
El chatbot utiliza un **árbol de conversación** implementado en JavaScript puro. Cada nodo del árbol contiene un mensaje y opciones que llevan al siguiente nodo:
```javascript
flows = {
  inicio: { msg: '...', opts: [...] },
  precio: { msg: '...', opts: [...] },
  tiempo: { msg: '...', opts: [...] }
}
```

### Detección de palabras clave
Cuando el usuario escribe manualmente, la función `send()` convierte el texto a minúsculas y usa expresiones regulares para detectar la intención:
```javascript
if (lower.match(/precio|costo|cuanto|gs|guarani/)) key = 'precio'
```

### Manejo de caso no reconocido
Si no se detecta ninguna palabra clave, el bot responde:
> "No entendí bien tu consulta 😅, pero puedo ayudarte con esto:"
Y muestra las opciones del inicio.

### Separación de responsabilidades
| Archivo | Responsabilidad |
|---------|----------------|
| `index.html` | Estructura HTML del chatbot |
| `style.css` | Estilos visuales del chatbot |
| `main.js` | Lógica completa del árbol de conversación |
