# T1 - Definición del Producto

## 1. Nombre del producto/servicio
MPStudio

## 2. Descripción clara
MPStudio es un servicio de diseño y desarrollo de páginas web profesionales
para empresas y emprendedores que desean tener presencia digital. Ofrecemos
sitios modernos, rápidos y completamente adaptados a las necesidades de cada
cliente, utilizando tecnologías actuales como Java con Spring Boot.

## 3. Público objetivo
- Emprendedores y pequeños negocios sin presencia digital
- Empresas que desean renovar su sitio web actual
- Profesionales independientes (médicos, abogados, contadores, etc.)
- Comercios locales que quieren vender o darse a conocer en internet

## 4. Problema que resuelve
Muchos negocios pierden clientes por no tener una página web o por tener
una desactualizada y poco profesional. MPStudio resuelve esto de forma
rápida y accesible, sin que el cliente necesite conocimientos técnicos.

## 5. Propuesta de valor
Páginas web profesionales entregadas en **7 días hábiles**, con diseño
personalizado, soporte post-entrega incluido y precios accesibles para
el mercado latinoamericano. Cada proyecto es único y orientado a resultados.

## 6. Preguntas frecuentes

1. **¿Cuánto cuesta una página web?**
   Los precios varían según el tipo de sitio. Contáctanos para recibir
   un presupuesto personalizado sin compromiso.

2. **¿Cuánto tiempo tarda en estar lista mi página?**
   El tiempo estimado de entrega es de 7 días hábiles desde la aprobación
   del diseño inicial.

3. **¿El servicio incluye hosting y dominio?**
   Sí, ofrecemos paquetes que incluyen hosting y dominio por el primer año.

4. **¿Puedo actualizar el contenido yo mismo?**
   Sí, entregamos el sitio con un panel de administración sencillo para
   que puedas editar textos e imágenes fácilmente.

5. **¿La página web funciona en celulares y tablets?**
   Absolutamente. Todos nuestros sitios son 100% responsive y se adaptan
   a cualquier dispositivo.

6. **¿Qué pasa si necesito cambios después de la entrega?**
   Incluimos un período de ajustes post-entrega de 15 días sin costo adicional.

7. **¿Trabajan con clientes fuera de Paraguay?**
   Sí, trabajamos con clientes de toda Latinoamérica de forma completamente remota.
